🗄️ ما هي قاعدة البيانات؟

قاعدة البيانات هي مجموعة منظمة من البيانات المخزنة إلكترونياً يمكن الوصول إليها وإدارتها بسهولة.

📊 أنواع قواعد البيانات

علائقية (Relational)

تستخدم جداول مترابطة. مثل: MySQL, PostgreSQL

غير علائقية (NoSQL)

مرنة وقابلة للتوسع. مثل: MongoDB, Redis

🔤 مفاهيم أساسية

  • الجدول (Table): يحتوي على صفوف وأعمدة
  • الصف (Row): سجل واحد من البيانات
  • العمود (Column): حقل محدد من البيانات
  • المفتاح الأساسي (Primary Key): معرف فريد لكل سجل

💻 أوامر SQL الأساسية

-- إنشاء جدول
CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    age INT,
    grade VARCHAR(10)
);

-- إضافة بيانات
INSERT INTO students (id, name, age, grade)
VALUES (1, 'أحمد', 20, 'A');

-- استرجاع البيانات
SELECT * FROM students;
SELECT name, grade FROM students WHERE age > 18;

-- تحديث البيانات
UPDATE students SET grade = 'A+' WHERE id = 1;

-- حذف البيانات
DELETE FROM students WHERE id = 1;

🔗 العلاقات بين الجداول

  • واحد لواحد (1:1): كل سجل في جدول يتطابق مع سجل واحد في جدول آخر
  • واحد لمتعدد (1:N): سجل واحد يرتبط بعدة سجلات
  • متعدد لمتعدد (N:M): عدة سجلات ترتبط بعدة سجلات
