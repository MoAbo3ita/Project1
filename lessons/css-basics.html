CSS للمبتدئين

تعلم تصميم وتنسيق مواقع الويب باحترافية

ما هو CSS؟

(CSS) اختصار لـ Cascading Style Sheets، وهي لغة تستخدم لوصف مظهر صفحات الويب المكتوبة بلغة HTML. إذا كان HTML هو هيكل المنزل، فإن CSS هو الطلاء والديكور الذي يجعله جميلاً وجذاباً.

باستخدام CSS يمكنك التحكم في الألوان والخطوط والحجم والتباعد والتخطيط والعديد من الجوانب المرئية الأخرى لأي عنصر في صفحة الويب.

لماذا نستخدم CSS؟

  • فصل المحتوى عن التصميم: HTML للمحتوى وCSS للتصميم
  • توفير الوقت: كتابة CSS مرة واحدة وتطبيقها على عدة صفحات
  • سهولة التعديل: تغيير التصميم من مكان واحد
  • تصميم متجاوب: مواقع تتكيف مع جميع أحجام الشاشات
  • تأثيرات جذابة: رسوم متحركة وتأثيرات بصرية

كيفية كتابة CSS

هناك ثلاث طرق لإضافة CSS لصفحة HTML:

1. CSS داخلي (Internal)

<head>
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>

2. CSS خارجي (External) - الأفضل

<head>
    <link rel="stylesheet" href="style.css">
</head>

3. CSS مضمن (Inline)

<h1 style="color: blue;">عنوان</h1>

بنية قاعدة CSS

selector {
    property: value;
}

مثال عملي:

h1 {
    color: blue;
    font-size: 24px;
    text-align: center;
}

أهم الخصائص في CSS

1. خصائص الألوان والخلفية

body {
    background-color: #f0f0f0;
    color: #333333;
}

2. خصائص الخطوط

p {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: bold;
}

3. خصائص الهوامش والحشو

div {
    margin: 20px;        /* الهامش الخارجي */
    padding: 10px;       /* الحشو الداخلي */
    border: 1px solid black;
}

أنواع المحديدات (Selectors)

  • عنصر: p { } - يطبق على جميع الفقرات
  • class: .classname { } - يطبق على عناصر محددة
  • id: #idname { } - يطبق على عنصر واحد فقط
